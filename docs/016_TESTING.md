# Testing

## Test Layers

- Unit tests
- Integration tests with temporary Git repositories
- VS Code extension tests
- Webview component tests
- End-to-end workflow tests
- Performance tests
- Security tests

## Required MVP Tests

- Detect a single repository.
- Detect nested repositories.
- Parse clean status.
- Parse staged files.
- Parse unstaged files.
- Parse untracked files.
- Parse conflicted files.
- Refresh repository state.
- Render repository tree.
