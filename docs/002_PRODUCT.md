# Product Specification

## User

The target user works in a VS Code workspace containing multiple Git repositories, nested repositories, submodules, or company project folders.

## Primary Workflows

- Inspect all repositories from one tree.
- See branch and dirty status for each repository.
- Open changed files and diffs.
- Stage, unstage, commit, pull, push, and fetch by clicking.
- Switch branches per repository.
- View commit history per repository.
- Merge or rebase with guided conflict handling.

## Product Modules

- Repository Explorer
- Git Operations
- Branch Manager
- Changes and Commit
- History and Graph
- Merge and Rebase
- Conflict Resolver
- Cache and Performance
- Settings and Logs
- Testing and Release
